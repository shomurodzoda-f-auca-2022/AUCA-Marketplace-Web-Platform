# AUCA Marketplace

AUCA Marketplace is a web application designed for students of the American University of Central Asia (AUCA) to buy, sell, and exchange items within a secure and convenient campus environment.

The platform provides a simple and user-friendly interface where students can create listings, browse available items, and contact sellers directly.

## 🚀 Features

- 🔐 User authentication (AUCA email required)
- 🛍 Create, edit, and delete item listings
- 🔎 Search functionality for finding items quickly
- 📄 Detailed item pages with full information
- 👤 User profiles with nicknames
- 🖼 Image upload for listings
- 📱 Clean and responsive UI

## 🧑‍💻 Tech Stack

- **Backend:** Python (Flask)
- **Frontend:** HTML, CSS, Jinja2
- **Database:** SQLite (SQLAlchemy ORM)
- **Authentication:** Flask-Login

## 🎯 Purpose

The goal of this project is to provide a centralized marketplace specifically for AUCA students, solving common issues such as scattered communication, lack of trust, and difficulty in finding relevant items within the university community.

## 🔒 Access

Only users with a valid `@auca.kg` email address can register and use the platform.

## 📸 Functionality Overview

- Users can browse listings without logging in
- Logged-in users can:
  - Add new items
  - Edit or delete their own listings
  - View detailed item information
- Each item is linked to its owner, ensuring secure and controlled access
